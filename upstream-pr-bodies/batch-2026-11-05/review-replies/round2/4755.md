## Thread: jjmata, cached offset and DST ("(-05:00) America/New York" wrong for part of the year)
`ActiveSupport::TimeZone#utc_offset` is the zone's base (standard) offset and does not change with daylight saving time, so the cached list stays the same all year; only a tzdata update changes it. That is also how Rails' own `time_zone_select` labels zones. To make this explicit, caf1372dd rewords the cache comment and adds the test "timezone labels show the standard offset during daylight saving time too", which builds the list under `travel_to` in July and still expects "(-05:00) America/New York" and "(+01:00) Europe/Berlin".
→ resolve
